Six gates

VValue

  • The step after an insight engine
  • One flagged opportunity to a signed, documented action
  • Detection coverage measured on a 300-household book

AAI-fit

  • The model never decides: verdicts, ranking, refusal are code
  • Template fragments where a model would compose
  • Read-only connectors; replaces none of the tools

LLabels

  • 300 households, 585 captured messages
  • Hand-reviewed sentence labels
  • The expected side imports no engine code

UUser-in-the-loop

  • Relay never sends
  • Nothing clears its own findings
  • Loosening a desk waits for a principal

EEvals

  • Cannot evaluate is reported, never clear
  • Eval seen failing on four deliberate breaks first
  • New phrasings go into labels first

DDeploy and drive

  • Rule-change proposer reads 90 days of findings
  • It can only propose tighter rules
  • Out of scope, said openly: persistence, CRM write-back

Decisions, and the alternative not taken

  • Deterministic decisions over model judgement. Eligibility, ranking and refusal are reproducible.
  • Prepare, never send over automation end to end. No outbound path exists in the code.
  • Tighten-only learning over self-tuning rules. Loosening needs a principal.

Risks and how they are held

  • Synthetic phrasing too narrow: held by labels first, then the fix
  • An agent clearing itself: held by requiresHuman in the engine, asserted in a test
  • A rule stated as current when it is not: validate() fails the build
