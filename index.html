Every AI use case clears six gates, before and after the model.

VALUED is a product lifecycle for AI: value, AI-fit, labels, user-in-the-loop, evals, deploy and drive. It starts before AI is chosen and ends long after launch. It is packaged as an agent workflow: the system drafts, the client decides.

Agent

I run one gate at a time. At each gate I draft something concrete, then ask the client at most two questions, with the product lead's recommendation first. Nothing moves to the next gate until the client has decided.

    How it runs

    One command, one line describing the case. An orchestrator calls one skill per gate; two agents do the work that benefits from separation.

    Agentprepared it Product leadrecommended it Clientdecided it
    Orchestrator and six gate skills. Draft the table for each gate, ask the cards, write the gate file and the running record of decisions.
    The product lead. Frames the case, puts a recommendation first on every card with the reason, and says what the table means.
    The client. Chooses on every card. The final brief lists each decision and who made it.
    /valued <case>
    Sets up the record of client decisions and assumptions, then runs the gates in order.
    A: three scorers in parallel
    use-case-scorer runs three times at once, on value and reuse, feasibility and data, and risk, so no single lens wins by accident. Each also names the lowest rung of the ladder that would work.
    L: the sealed holdout
    The golden set is written before any system exists. Ten rows are moved to a holdout that the builder never sees.
    E: the background build
    prototype-builder writes a deterministic router before it may open the golden set, then an eval runner. A missed gate blocks the release. A fix may change the router, never the labels, and is then scored on the holdout.
    Brief
    One page: the recommendation, six gates, release gates, the plan, and every decision the client made.

    Principles

    The system drafts, the client decides.No gate makes a judgement call on the client's behalf.
    Least AI that works.Rules, then classic ML, then retrieval and a model, then an agent. Climb only when the rung below fails.
    Labels before the model.Otherwise the system is graded against itself.
    Metrics by slice.An average hides a broken language or segment. A slice gate does not.
    The builder never sees the holdout.A fix is scored on rows it learned from and on rows it never saw. The second number is the honest one.
    Escalation wins every race.If a stop condition fires, nothing else is drafted.
